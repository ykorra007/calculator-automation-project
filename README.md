# Calculator Automation Project

## Overview

A Java-based Calculator Application developed and tested using JUnit 5.

## Features

- Addition
- Subtraction
- Multiplication
- Division
- Division By Zero Exception Handling

## Automated Test Cases

- additionShouldReturnCorrectResult()
- subtractionShouldReturnCorrectResult()
- multiplicationShouldReturnCorrectResult()
- divisionShouldReturnCorrectResult()
- divisionByZeroShouldThrowException()

## Technologies

- Java
- Maven
- JUnit 5
